# SENTINEL UI 风格规范 v1.0

> **v1.1 修订（2026-08-02）**：① 强调色 `accent` 由 iOS 蓝 `#007AFF` 改为 **Kimi（月之暗面）官方标志性紫色 `#6B5CE7`**，整体气质对齐 Kimi 官方极简、克制、微动效风格；② 顶栏 provider·model·思考深度由三个独立下拉改为**一个级联主菜单（provider → model → 思考深度下钻）**；③ AI 输出改为 **Markdown 渲染**，命令/代码统一用**深色代码块**；④ 移除开发期调色盘（design showcase）入口；⑤ 侧边栏点会话语义修正为「切换」而非「给主屏加可切换会话」；⑥「停」键与 AI 输出态关联（中继 session.busy 驱动）。暗色主题（月之暗面签名形态）登记为可选变体，浅色（月之亮面）仍为 v1 默认。

## 一、设计基调

> **冷静、纯粹、克制，但在"需要你拍板"的时刻清晰可辨。**
> 大面积中性灰白让内容（活的流）成为绝对主角；语义色只在批准卡、状态点、关键按钮等"决策点"出现，占比 ≤5%。紧急性靠**推送（锁屏门铃）**保证，App 内批准卡用**静态色条 + 柔和阴影**突出，不用脉冲动画——这是规范"理性克制"的要求，也避免手机上一个劲闪的廉价感。
> **对齐 Kimi 官方**：极简留白、单一焦点、微动效反馈（按压收缩 / 呼吸点 / 渐变遮罩），强调色用 Kimi 紫而非系统蓝。

## 二、色彩令牌（85/5/10 → 中性主导 + 语义克制）

**中性色阶（85%，全局基调）**

| 角色 | 色值 | 用途 |
|---|---|---|
| `background` | `#F7F8FA` | 主背景（scaffold） |
| `surface` | `#FFFFFF` | 卡片、批准卡、输入框、弹窗 |
| `keyCap` | `#E5E5EA` | 快捷 chip、浅灰圆形图标底 |
| `textPrimary` | `#1D1D1F` | 标题、agent 回复、用户消息 |
| `textSecondary` | `#86868B` | 副标题、时间、cwd、说明 |
| `placeholder` | `#C0C0C0` | 输入框占位符 |
| `hairline` | `#EEF0F2` | 极淡分隔（规范主张不用分割线，仅必要时） |

**语义色（5%，仅决策点）—— 从规范装饰色板派生，低饱和**

| 角色 | 色值 | 用途（克制使用） |
|---|---|---|
| `accent` | `#6B5CE7`（Kimi 紫） | 选中态、C 位高亮、链接、当前会话标记（对齐 Kimi 官方标志色） |
| `approve` / `online` | `#34C759`（草绿） | 批准按钮、🟢在线、工具完成✓ |
| `reject` / `critical` | `#FF3B30`（暗红） | 拒绝按钮、关键命令色条、🔴待批准、失败✗ |
| `warning` / `pending` | `#FF9500`（琥珀） | 🟡降级、将睡预警、待批准角标 |
| `think` | `#8E8E93`（中性灰） | 思考块（不用彩色，保持冷静） |

**装饰色板（10%，仅点阵/悬浮球）**：淡蓝 `#A7C7E7` · 草绿 `#A8D5A2` · 淡紫 `#C3B1E1` · 暗红 `#E8A0A0` · 粉红 `#F4C2C2`，灰度为主点缀，用于点阵艺术与悬浮球（AI 神经网络隐喻）。

## 三、字体排版令牌（系统字体，规范字号字重）

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| `title1` | 17 / Medium | 页面标题、会话名 |
| `title2` | 16 / Medium | 批准卡标题、弹窗标题 |
| `body` | 15 / Regular | agent 回复、用户消息、正文 |
| `callout` | 13 / Regular | 工具卡描述、列表项 |
| `caption` | 12 / Regular（textSecondary） | 时间、cwd、token 用量 |
| `mono` | 12 / Regular（系统等宽） | 命令、输出、机器体检配置 |

> 字体用系统默认（iOS = San Francisco，中文 = PingFang SC），不引第三方字体——规范明确要求，也保证跨平台一致与轻量。等宽用系统等宽（SFMono/Cupertino）。

## 四、间距 / 圆角 / 阴影令牌

- **间距**：页边距 `16`（紧凑）/`20`（宽松）；列表项间距 `16`；元素间距阶梯 `4/8/12/16/24`。严禁贴边。
- **圆角**：卡片/批准卡/输入框 `20`；缩略图/工具卡 `12`；胶囊按钮/状态点 `999`（全圆角）。
- **阴影（柔和弥散，非硬边）**：
    - 卡片：`color black 6%, blur 24, offset (0,8)` —— 悬浮感
    - 输入框：`color black 5%, blur 12, offset (0,4)` —— 底部轻浮起
    - 弹窗：`color black 10%, blur 32, offset (0,12)`

## 五、SENTINEL 核心组件设计约定（规范 → 产品）

| 组件 | 规范套用 | SENTINEL 适配 |
|---|---|---|
| **批准卡** | 白底卡片、圆角 20、柔和阴影 | 左侧 **3px 语义色条**（关键命令=`reject` 红，普通=中性）+ 标题 + 深色代码块命令 + 理由；底部**胶囊按钮**：批准=`approve` 绿底、本会话=浅灰、拒绝=`reject` 红文字。待批准用**静态**色条+略重阴影突出，**不脉冲**（紧急性靠推送） |
| **活的流** | 内容区垂直流式单列、大量留白 | agent 回复=**左对齐无气泡纯文字，按 Markdown 渲染**（标题/加粗/行内码/代码块/列表/引用）；用户消息=**右对齐 `accent` 淡底气泡**；思考=可折叠浅灰块；工具卡=白底卡片+左色条+**深色代码块**命令/输出 |
| **代码块 / 命令** | 等宽、浅底或深底 | 统一用**深色代码块**（`textPrimary` 深底 + 浅色等宽字、可选中、横向滚动），代码块可带语言标签；与 Kimi 官方代码呈现一致，命令不裸排在浅底上 |
| **三态灯** | 线性/几何、克制 | 顶部导航右侧小圆点：🟢`approve` / 🟡`warning` / ⚫`placeholder`，直径 8px，不抢 |
| **顶部导航** | 三段式：左汉堡/中标签/右工具 | 左=📜历史抽屉入口；中=**级联配置菜单**（provider→model→思考深度下钻，短标签触发器）；右=三态灯 + mode 图标菜单 |
| **底部输入区** | 大圆角近胶囊输入框，左+号右功能键 | 输入框圆角 20、白底、底部轻阴影；左 `+` 号（浅灰圆底，点开快捷命令/slash 菜单）；右**发送按钮**（深灰圆），**流式中变为红色「停」**（session.busy 驱动）；语音位 v3 再加 |
| **历史项** | 列表项：左图标+文本，右辅助信息，无分割线 | 左状态点（活跃=绿/历史=灰）+ 标题；右=相对时间 + cwd 末段（caption）；间距区分，无分割线 |
| **悬浮球**（v1 可选） | 圆形多色圆点、右侧边缘、AI 隐喻 | **哨兵的视觉化身**：平时静置右侧（装饰色板圆点），有待批准时成为入口（点开待批准队列）。规范的装饰元素 → 产品功能 |
| **点阵装饰** | 多色圆点矩阵、克制 | 用于**空状态**（无活跃会话）、历史抽屉顶部、机器体检页，作品牌符号，不干扰内容 |
